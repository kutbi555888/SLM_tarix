# Tashqi manbalar qaydi

| Manba | Ushbu loyihadagi o‘rni |
|---|---|
| [davronbek-malikov/LLM_Model](https://github.com/davronbek-malikov/LLM_Model) | Boshlang‘ich loyiha va papka tuzilmasi |
| [Wikimedia Wikipedia dataset](https://huggingface.co/datasets/wikimedia/wikipedia) | O‘zbekcha boshlang‘ich matnlar |
| [PyTorch](https://pytorch.org/) | Tensorlar, Transformer hisoblari va o‘qitish |
| [Hugging Face Tokenizers](https://huggingface.co/docs/tokenizers/) | Matnni tokenlarga ajratish |
| [Hugging Face Datasets](https://huggingface.co/docs/datasets/) | Manba ma’lumotini o‘qish |
| [FastAPI](https://fastapi.tiangolo.com/) | Mahalliy HTTP server |

Tashqi kod kutubxonalari ZIP ichiga ko‘chirilmagan; `requirements.txt` orqali o‘rnatiladi. Ularning litsenziyalari o‘z tarqatmalarida saqlanadi.

Wikipedia matnlarining sarlavhasi, URL manzili, mualliflik qaydi va litsenziya maydoni har bir JSONL yozuvda saqlangan. Bu qaydlarni matnlar bilan birga saqlang. Asl GitHub kodiga berilmagan litsenziya nomidan yangi ruxsat chiqarilmagan; `LICENSE.md`ni o‘qing.
